# Lumée Collector（浏览器采集插件）

在 1688、速卖通、Temu、淘宝/天猫、Amazon 等网站上，把商品一键采集到店铺后台「商品 › 采集」的待审核列表。需要登录或有访问防护、服务器无法直接读取的网站，也能采集。

## 安装（开发者模式）
1. Chrome 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点「加载已解压的扩展程序」，选择这个 `extension` 文件夹。插件更新后，在同一页面点插件卡片上的刷新按钮。
3. 在后台「商品 › 采集 › 浏览器插件」点「生成连接码」并复制。粘贴到插件的「设置」里，再点「保存并测试连接」。

## 功能

**当前页采集**：先预览，再发送。
- 预览时可以修改标题、挑选图片（第一张作为主图）、选择货币、加标签。
- 可以查看全部 SKU 明细：规格、价格、库存。
- 已经采集过的商品会显示提示；再次采集会更新原来的记录，已上架的商品不会被覆盖。

**完整 SKU**：
- 速卖通：已按 2026 年的真实页面核对过。可以读取全部规格组合（实测一个商品有 189 个 SKU），以及每个 SKU 的售价、原价、库存、图片和 SKU 编号，还有店铺名、规格参数表和商品详情描述。
- 1688、Temu、淘宝/天猫：读取规格、每个 SKU 的价格、库存和图片。这几个平台要先登录，没有在真实页面上核对过。
- 其他网站：读取标题、图片、价格。
  - Amazon、SHEIN、eBay、Etsy、Walmart、TikTok Shop、Shopee、Lazada、Mercado Libre
  - Shopify、WooCommerce 店铺
  - 带 schema.org 商品数据的网站

**高清图片**：自动去掉缩略图尺寸后缀（阿里图床、1688、Amazon、eBay），拿到原图。

**批量采集**：
- 在搜索结果、店铺或分类页点「扫描」，可以选择扫描 1、2、3、5 或 10 页。插件会自动往下滚动，把懒加载的商品加载出来，再自动翻页（链接、翻页按钮、`?page=` 都支持），到最后一页自动停止。实测速卖通扫描 2 页找到 89 个商品。
- 勾选商品后开始采集，也可以直接粘贴链接。已经采集过的商品会标出来，可以一键「只选未采集的」。
- 插件在后台标签页里逐个打开、像人一样往下浏览、读取、发送，完成后关闭标签页。

**防封保护**（在「设置」里调整）：
- 每个商品之间随机间隔，默认 8–20 秒。
- 每采集 25 个休息 3 分钟。
- 每天最多采集 150 个，达到上限后第二天自动继续。
- 遇到验证码（滑块）或登录页时，立即暂停整个队列，打开那个页面，插件图标显示红色的「!」。你在页面上完成验证或登录后，队列会自动继续。
- 单个商品采集时如果弹出验证、但商品数据已经读到，会照常采集，并提醒你先完成验证再继续。

**页面按钮**：商品页右下角会显示「采集到 Lumée」按钮。可以在设置里关闭，也可以点按钮旁的 ✕ 只在某个网站隐藏。

**右键菜单**：
- 在页面上点右键：「采集这个商品」。
- 在商品链接上点右键：「采集这个链接的商品」，加入后台队列。

**快捷键**：`Alt+Shift+S` 不用打开插件，直接采集当前页。

**采集记录**：最近 200 条，包括成功的和失败的；失败的会写明原因。

## 工作方式和隐私
- 只有在你采集时，插件才会读取页面。读取的内容只发送到你连接的店铺后台。
- 服务器优先使用插件读出的平台 SKU 数据。没有这些数据时，再用页面里的结构化商品数据（schema.org JSON-LD、Open Graph）。
- 连接密钥只能把商品发送到这个店铺的采集列表，不能登录后台。在后台重新生成后，旧的连接码立即失效。
- 需要登录的网站，请先在浏览器里登录。
- 没有插件能保证永远不被限制。防封保护的作用是把采集速度降到接近真人浏览，并且遇到验证就停下来；越慢越安全。
