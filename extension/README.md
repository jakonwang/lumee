# Lumée Collector（浏览器采集插件）

把正在看的商品页发送到店铺后台「商品 › 采集」的待审核列表。适合需要登录或有访问防护、服务器无法直接读取的网站，比如 1688、速卖通、Temu。

## 安装（开发者模式）
1. Chrome 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点「加载已解压的扩展程序」，选择这个 `extension` 文件夹。
3. 在后台「商品 › 采集 › 浏览器插件」生成连接密钥，把后台地址和密钥填进插件的设置。

## 工作方式
- 只有点「采集此页」时，插件才读取当前标签页：页面 HTML，加上它推测出的标题、大图和价格。
- 服务器优先解析页面里的结构化商品数据（schema.org JSON-LD、Open Graph）。找不到时，才使用插件推测的内容。
- 连接密钥只能把商品发送到这个店铺的采集列表，不能登录后台。在后台重新生成密钥后，旧密钥立即失效。
- 插件只申请访问你填写的后台地址。
